# Movie Night Planner

A mini React project for browsing movies, filtering by genre, building a watchlist, and generating a simple movie-night schedule — styled like a dark-mode streaming platform.

## Features
- Browse predefined movies (`src/data/movies.js`)
- Filter movies by genre
- Add/remove movies from a watchlist
- Auto-calculated total watch time
- Generate a sequential schedule with start/end times (with a 15-min break between movies)
- Netflix-style horizontally scrolling carousels with hover-zoom cards
